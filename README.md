# Strike Force 🎮

**Strike Force** is a browser-based 3D first-person shooter (FPS) featuring immersive environments, fast-paced combat, and objective-based game modes.

## 🎯 Game Modes

- **Team Deathmatch** — Compete against the opposing team to score eliminations.

## ✨ Features

- 3D environments and first-person gameplay
- Browser-based gameplay
- Built using modern web technologies

## 🛠️ Technologies

- TypeScript
- React
- Three.js
- Vite
- HTML and CSS

## 🚀 Run Locally

Make sure Node.js is installed, then run:

```
npm install
npm run dev
```

Open the local URL displayed in your terminal.

## 📌 Project Status

Under development. Features and gameplay may change as development continues.
